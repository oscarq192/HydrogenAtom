# Hydrogen Atom Visualisation

This project is a visualisation of the energy levels of the hydrogen atom. It uses a point cloud visual to show possible positions for an electron.

The motivation for this project was to gain a deeper understanding of applications of the Schrödinger equation and how it arises from the proposition that particles can be represented as waves. This was hypothesised by de Broglie in 1924, motivated by Einstein's earlier suggestion that light, traditionally thought to be a wave, could behave as a particle. The converse formulation - the de Broglie wavelength - can be used along with the Planck relation to derive the Schrödinger equation.

The attached pdf "Electron Probabilities.pdf" has handwritten notes with a derivation starting from the wave equation that progress through: the Schrödinger equation, the infinite square well and boundary conditions, the harmonic oscillator, the radial Schrödinger equation and the wavefunction of the hydrogen atom, including the Bohr radius, and a numerical method to solve the radial equation.

## Derivation 
See The_Hydrogen_Atom.pdf for LaTeX write up of notes. Where relevant, the appropriate working is shown in the handwritten notes.

## Program

Run using .exe file. Raw Python code visible in hydrogen_atom.py. Use the GUI on the left of the screen to change n, l, m, colour and cross-section toggle. Click and drag to pan, scroll to zoom. Note that the colour shows probability density.
